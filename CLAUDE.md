# Dash & Newt — agent guide

Remotion project producing vertical (1080×1920, 30 fps, 30–45 s) **Dash & Newt** comedy cartoon reels. This repo is only for Dash & Newt.
Read `docs/PLAYBOOK.md` before making an episode and `docs/CAST.md` before touching a character.

## Layout

- `src/rig/` — shared stickman rig. Add new poses/faces to `library.ts`, new body props to `Stickman.tsx` + `types.ts` (`Extras`). Never fork the rig per episode.
- `src/rig3d/Toon3D.tsx` + `src/world3d/` — **the default look for every new episode (from ep11)**: Dash & Newt as chunky, big-headed 3D cartoon characters in a bright 3D world (saturated sky, puffy clouds, soft sun shadows, blurred background, no ink outlines), matching the user's reference thumbnails. `<Stage3D cam set="beach|park|street|studio">` holds camera, lights, sky, set and post; put `<Toon3D who="dash|newt" c={charState} turn={35} />` and the episode's 3D props inside it. `Toon3D` reads the same `CharState`, so poses/faces/Scripts/physics are shared. New sets and reusable props go in `world3d/sets.tsx` / `kit.tsx` (procedural and seeded, no downloaded assets). Model sheet + look stills: `CastSheet3D`, `LookBeach`, `LookPark`, `LookStreet`. Render 3D with `--gl=angle`.
- `src/rig3d/Stickman3D.tsx` — the older vinyl-toy 3D figure used by ep06 (`Kitchen3D.tsx`, inked look). Kept for that episode only.
- `src/rig2d/` — Dash & Newt as full 2D cartoon characters (`Toon`, clothes/skin/hair) from the same `CharState`; `ik.ts` keeps joints anatomical and places holding hands with 2-bone IK. The look of ep07–ep10; superseded by the 3D look above (the user supplied 3D reference thumbnails on 2026-11-10 and asked for all future episodes to match them). Model sheet: the `CastSheet` still.
- `src/episodes/epNN-slug/` — `timeline.ts` (beat times + derived physics), `cast.ts` (Scripts), `props.tsx`, composition. Register in `src/Root.tsx`.
- `public/sfx/` is generated by seeded `tools/sfx/*.py` (run with `python3 -I`; `npm run sfx` rebuilds all, byte-for-byte; the folder is git-ignored, so a fresh clone runs `npm run setup` first). Most are stdlib only; ep06+ may use numpy/scipy from the git-ignored `.venv/` (`build.sh` uses it when present) and the skill's sound kit in `tools/sfx/kit3d/` (MIT). `house.py` is the shared kit incl. the character signatures (`hero-blip`, `womp`, `hero-scream`; `kid-blip`, `kid-win`, `chalk`). New sounds go in a generator, never hand-dropped files.
- `tools/publish/` is the review-gated publisher (docs/PUBLISHING.md). Platform copy comes from each episode sheet's `## Publish brief` → `content/publish/epNN-slug.yaml`. Only the user approves (`publish:approve`); you may run `publish:prepare`, `publish:status` and `publish -- <ep> --dry-run`. Never read or edit `.secrets/` (settings + tokens) or ask for tokens; never put publishing secrets in `.env`/`.env.local` — Remotion loads those into the bundle.

## Rules

- The cast is locked: Hero (orange scarf) **plays dumb**, brute force; Kid (party hat + blush) is **the physics genius** with a chalk-overlay "physics look". One physics principle per episode.
- Reels are **monetized**: minimal or no voice; only generated or commercially licensed audio. No stock/meme clips anywhere (they were removed from the library), never OmniVoice output (non-commercial).
- Every consequence needs a visible cause; motion follows `physics.ts` (ballistic, decelerate, particle, damped) with one `G`. Bodies must not overlap — move one, or use a depth lane.
- Times live in `timeline.ts`; derive dependent events (landing times, impact points) from physics instead of hand-tuning.
- Animate with `useCurrentFrame()`-driven keyframes only (no CSS transitions).
- One named `<Audio>` node per sound cue.

## Verify every change

1. `npx tsc --noEmit`
2. Render stills at each beat (`npx remotion still <Id> out.png --frame=N --scale=0.35`), tile with ffmpeg, and look at them: overlaps, expressions, identity, readability without sound.
3. `bash tools/render.sh <Id>` for the final (adds the audio limiter).
