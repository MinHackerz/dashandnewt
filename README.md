# Dash & Newt

Funny, meaningful **Dash & Newt** cartoon reels (vertical 1080×1920, 30 fps) built with
[Remotion](https://www.remotion.dev). Dash (orange scarf) plays dumb and tries brute force;
Newt (party hat) knows the physics and wins, then is kind about it. One physics principle
per episode, no voice, all sound generated.

Characters: [docs/CAST.md](docs/CAST.md) · How to make an episode: [docs/PLAYBOOK.md](docs/PLAYBOOK.md)

## Quick start

```bash
npm i
npm run setup                        # first time after cloning: Python venv (numpy/scipy) + generate public/sfx
npm run studio                       # live preview of every episode + the CastSheet model sheet
npm run render -- OneFlare           # → out/one-flare.mp4 (peak-limited audio)
npm run render -- OneFlare --draft
npm run sfx                          # rebuild public/sfx (all original, generated)
```

## Publishing (review-gated)

```bash
npm run publish:prepare -- ep10              # draft SEO metadata → content/publish/ep10-one-flare.yaml
npm run publish:approve -- ep10              # review everything, type "ep10" to approve
npm run publish -- ep10 --dry-run            # the exact API requests, nothing sent
npm run publish -- ep10                      # YouTube Shorts + Instagram Reels + Facebook Page Reels
npm run publish:status
```

Nothing is uploaded unless the episode is approved, and an approval is void if the video or the
text changes afterwards. Re-runs never double-post. One-time credential setup and token renewal:
[docs/PUBLISHING.md](docs/PUBLISHING.md).

## Layout

```
src/
  Root.tsx                     # registers every episode composition
  rig/                         # shared character state: joints, faces, poses, gaits, Script/build
  rig2d/                       # Dash & Newt as 2D cartoon characters (Toon, IK, depth lanes, CastSheet)
  rig3d/                       # the same rig in three.js (ep06)
  lib/                         # keyframes (kf.ts), readability helpers, 3D post-processing
  shared/                      # house font/UI, chalk "physics look" overlay, moral card
  channel/                     # channel avatar + banner stills
  episodes/epNN-slug/          # one folder per episode (timeline, cast, props, composition)
public/sfx/                    # sound library (100% original, generated by `npm run sfx`; git-ignored)
tools/
  render.sh                    # render + audio limiter + publish draft
  review/stills.mjs            # beat stills for review
  sfx/                         # seeded SFX synthesizers: house kit + per-episode (byte-reproducible)
  publish/                     # review-gated YouTube / Instagram / Facebook publisher
content/
  episodes/                    # story sheet, beats, Publish brief per episode
  channel/                     # brand, profile copy, publish-defaults.yaml
  publish/                     # generated per-episode publish files (review → approve → results)
docs/
  CAST.md                      # character bible (look, personality, sound, identity rules)
  PLAYBOOK.md                  # idea → story → build → sound → review → publish
  PUBLISHING.md                # publishing pipeline, platform setup, tokens
```

## House rules

1. **Same characters, same identity** — Dash = orange scarf, Newt = party hat ([CAST](docs/CAST.md)).
2. **Every effect has a visible cause; physics is real** (one gravity, momentum, friction, inertia).
3. **Story arc:** setup → three escalations → twist → heart → two-line moral.
4. **Every action has a sound; every beat has an expression.** No voice.
5. **Review stills before rendering** — see [PLAYBOOK](docs/PLAYBOOK.md).

Remotion is free for individuals and teams up to 3; larger companies need a
[company license](https://www.remotion.pro/license).
