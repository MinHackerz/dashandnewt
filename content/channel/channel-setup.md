# Channel setup pack — YouTube · Instagram · Facebook

Copy-paste text for setting up all three profiles, SEO-tuned and consistent with each other. Every
field shows its limit, and `node tools/publish/check-channel-copy.mjs` checks them all. Brand, assets
and the "made for kids" decision are in [youtube-channel.md](youtube-channel.md). Per-episode copy
comes from the publish pipeline ([docs/PUBLISHING.md](../../docs/PUBLISHING.md)).

**Search strategy.** One primary phrase, **stickman animation**, goes in the first line of every
profile. Support it with *funny animation*, *animated shorts*, *funny physics* / *physics comedy*,
*no dialogue* and the brand *Dash & Newt*. Use the same name, handle, avatar and tagline everywhere,
so search engines and viewers link the three accounts together. Wording stays general-audience:
no "for kids", "nursery" or "children's" (see the audience note in youtube-channel.md).

**What actually moves rankings:** the first line and title of each upload, the hook in the first
second, and watch-through. Profile keywords help YouTube understand the channel, but they're a
small signal. Get them right once, then forget them.

## YouTube

### Channel description: Customization → Profile → Description (≤ 1,000 characters)

The first ~150 characters show in search results and on the channel header, so the keywords and
the promise come first.

```text
Funny stickman animation shorts where brute force meets physics. 🧠⚡ A new 30-second cartoon every week — no dialogue, real physics, one tiny lesson.

Dash (orange scarf) always picks the dumb way: he presses the DO NOT PRESS button, hits snooze for 40 years and takes "shortcuts" through cactus fields and angry bulls. Newt (party hat) actually knows physics — gravity, inertia, friction, momentum — and wins every time. Then he shares the cake.

What you'll find here:
🎬 Stickman comedy shorts — 30–45 second 2D animation
⚛️ Funny physics — every fall, splash and bounce follows real physics
🔇 No dialogue — funny in any language, even on mute
📌 A two-line moral at the end of every episode

Funny first, secretly educational. Subscribe and watch Dash learn physics the hard way. 🔔

Dash & Newt — brute force vs. physics.
```

### Channel keywords: Settings → Channel → Basic info → Keywords (≤ 500 characters)

Paste as one line. Studio wraps multi-word phrases in quotes, and those quotes count toward the limit.

```keywords
dash and newt, stickman animation, stickman, stick figure animation, funny animation, animated shorts, cartoon shorts, 2d animation, funny physics, physics comedy, physics cartoon, comedy shorts, stickman comedy, no dialogue animation, silent comedy, funny cartoon, animation shorts, relatable animation, funny shorts, cartoon animation, stick man animation, brute force vs physics
```

## Instagram (professional account)

Instagram search matches the **name** as well as the username, so the main keyword goes here.
You can only change the name twice in 14 days, so get it right the first time.

## Setup order (≈30 minutes)

1. Claim the handle on all three platforms first (`@DashAndNewt` / `dashandnewt`), so they match.
2. **YouTube:** avatar, banner, description, keywords, links, playlists (with descriptions),
   watermark, layout. The channel trailer comes after the first upload.
3. **Instagram:** switch to a professional account. Set the name, bio, category and links, then
   link the Facebook Page (needed for API publishing; see docs/PUBLISHING.md).
4. **Facebook Page:** name, username, categories, bio, details, avatar, cover, action button, linked Instagram.
5. Re-check the YouTube *Links* now that the Instagram and Facebook URLs exist.
